# ゲーム企画書（Game Design Document）

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| **ゲームタイトル（仮）** | **RogueLabyrinth（ローグラビリンス）** |
| **ジャンル** | 王道ターン制ダンジョン探索型ローグライクRPG（不思議のダンジョン系） |
| **プラットフォーム** | Webブラウザ（PC / スマートフォン・タブレット両対応） |
| **動作形態** | 完全オフライン動作 SPA（Single Page Application / PWA対応） |
| **対象層** | 手軽に本格的なローグライクを遊びたいプレイヤー、スキマ時間にじっくり思考型ゲームを楽しみたいユーザー |
| **画面比率** | レスポンシブ（PC横長、スマホ縦持ち・横持ちの全画面に追従） |

## 2. コンセプト & コア体験

### コンセプト
**「いつでも、どこでも、電波がなくても。1歩の選択が命運を分ける、手のひらの本格ローグライク」**

### プレイヤーに提供する体験
1. **純粋な戦略と思考の快感**
   - 「1歩動けば、敵も1歩動く」同時ターン制。反射神経やアクション操作は一切不要。
   - ピンチのときにアイテム袋を開き、「どのアイテムを切るか」を熟考して逆転するカタルシス。
2. **快適なマルチデバイス・レスポンシブ体験**
   - スマホの縦持ち片手操作でも、PCのテンキー/マウスでも、一切のストレスがない直感的な操作性。
3. **完全オフライン＆オートセーブによる安心感**
   - 通信環境を一切必要とせず、飛行機内や地下鉄でも完全に動作。
   - 1歩ごとに自動セーブされるため、ブラウザを突然閉じても中断したその瞬間の状態から復帰可能。

## 4. ゲームシステム詳細

### 4.1. ターンシステム
- **同時ターン制**:
  - プレイヤーが「行動（移動、攻撃、アイテム使用、足踏み）」を完了すると、世界全体の時間が1ターン経過する。
  - フロア内の全モンスターが1回ずつ自律行動を行う。
- **行動優先順位**:
  1. プレイヤーのアクション
  2. プレイヤーのアクションに伴う効果（ダメージ判定、状態変化）
  3. 各モンスターの行動（プレイヤーへの接近、特殊行動、攻撃）
  4. ターン終了時処理（毒・リジェネ等の状態異常効果、満腹度消費、HP自然回復）

### 4.2. パラメータとリソース
- **HP（体力）**: 0になるとゲームオーバー。足踏みや歩行で少しずつ自然回復するが、満腹度を消費する。
- **満腹度（Hunger）**: 最大100%。歩行やターン経過で徐々に減少。0%になると毎ターンHPが減少する餓死の危機に瀕する。食料アイテム（パン・リンゴ等）で回復。
- **Lv（レベル） & EXP（経験値）**: 敵を倒すことで上昇。HP最大値・攻撃力・防御力が成長。
- **ATK（攻撃力） / DEF（防御力）**: 装備品（武器・盾）によって強化。

### 4.3. ダンジョン生成ルール
- **BSP（二分空間分割法）による部屋と通路の生成**:
  - 各フロアは一定数の部屋と、それらを繋ぐ通路（1マス幅）で構成。
  - 部屋内は視界が開けており、通路内は前後数マスしか見えない（暗闇・視界制限）。
- **配置物**:
  - **階段（下り/上り）**: 必ずスタート部屋とは別の部屋に生成。
  - **アイテム**: フロア規模に応じてランダムに配置。
  - **罠（Trap）**: 隠された罠（踏むと毒、ワープ、落とし穴、回転など）。素振り（空振り）や探知で発見可能。
  - **モンスター**: 各部屋にランダム配置。未発見状態では部屋内を巡回・睡眠中。

### 4.4. アイテム体系
アイテムは大きく分けて以下の5カテゴリに分類される：

| カテゴリ | アイテム例 | 効果・役割 |
|---|---|---|
| **装備品** | 剣、斧、短剣、木の盾、鉄の盾 | 装備することでステータス永続強化。強化値（+1等）や呪い要素 |
| **食料** | パン、大きいパン、薬草の実 | 満腹度を大幅回復。リソース管理の要 |
| **ポーション（薬）** | 薬草、回復薬、力の種、混乱薬 | 飲むことでHP回復やステータスアップ。敵に投げつけて状態異常を付与可能 |
| **巻物（スクロール）** | ワープの巻物、明かりの巻物、混乱の巻物、炎の巻物 | 読むことで部屋全体や周囲に広範囲効果を発揮する強力な使い捨てアイテム |
| **杖・魔導具** | 吹き飛ばしの杖、場所替えの杖、金縛りの杖 | 回数制限（Charges）のある遠距離射出アイテム。位置取りの逆転に必須 |

## 5. 操作体系・レスポンシブUI仕様

### 5.1. デバイス共通のアクション定義
ゲーム内のすべての入力は、内部的に以下の抽象アクション（`GameAction`）に変換される：
- `MOVE(dx, dy)`: 8方向への移動
- `ATTACK(dx, dy)`: 指定方向への攻撃
- `WAIT`: 足踏み（HP自然回復）
- `INTERACT`: 足元のアイテムを拾う / 階段を降りる
- `OPEN_INVENTORY`: 持ち物画面の開閉
- `USE_ITEM(slot, target)`: アイテムの使用・装備・投擲・配置

### 5.2. PC（デスクトップ）での操作
- **キーボード**:
  - 移動/攻撃: `テンキー(1-9)` / `WASD` + 斜めキー / `矢印キー`
  - 斜め移動固定: `Shift` キー押しながら移動
  - 方向転換のみ（ターン消費なし）: `Ctrl` + 矢印/テンキー
  - 足踏み: `Space` または `テンキー 5`
  - 階段降り/足元: `Enter` または `E`
  - インベントリ: `I` または `Tab`
- **マウス**:
  - マップ上の隣接セルクリック: 移動または攻撃
  - 離れたセルクリック: 自動最短経路歩行（A* Pathfinding）
  - 右クリック / 長押し: オブジェクト情報確認（インスペクト）

### 5.3. スマートフォンでの操作（縦持ち・横持ち対応）
- **オンスクリーン・コントロール**:
  - **画面下部 仮想十字キー（8方向パッド）**: 直感的な親指操作。斜め入力ボタン付き。
  - **クイックアクションボタン**: [攻撃/調べる][足踏み][インベントリ][向き変更] を親指が届く範囲に大型配置。
- **ジェスチャー操作**:
  - スワイプ: その方向へ1歩移動/攻撃
  - ダブルタップ: その場足踏み
  - ピンチイン/アウト: マップ表示の拡大・縮小（ズーム）
  - マップドラッグ: カメラのスクロール（パン）
- **画面向きのレスポンシブ切り替え**:
  - **スマホ縦持ち（Portrait）**:
    - 上部（55%）: ダンジョンビュー（プレイヤー中心追従）
    - 下部（45%）: 操作パッド、ミニステータスバー、クイックアイテムスロット
  - **スマホ横持ち（Landscape）/ PC（Desktop）**:
    - 中央・左（70%）: ワイドダンジョンビュー
    - 右側（30%）: ステータスパネル、常時表示ログ、インベントリ一覧

## 6. アートスタイル & サウンド方針

- **ビジュアル**:
  - クリーン＆レトロな **モダン・ピクセルアート（ドット絵風）**、または幾何学アイコンによるハイコントラストな視認性の高いスタイル。
  - タイルマップ（壁、床、水路、階段）とキャラクタースプライトをCSS Canvasで高速描画。
  - 視界外（Fog of War）は滑らかな暗黒グラデーション処理。
- **サウンド（Web Audio API）**:
  - 完全にオフラインで動作する軽量なシンセサイズSE（効果音）または軽量なOGG/MP3アセット。
  - 足音、攻撃ヒット音、階段を降りる音、アイテム入手音、レベルアップファンファーレ。

## 7. 将来の拡張性（ロードモナーク・The Tower要素の統合可能性）
- **ミニオン・仲間モンスターの自律使役（モナーク要素）**:
  - 杖や巻物で召喚した仲間が、部屋内を自律的に探索・警備し、プレイヤーに代わって戦うAIシステムの拡張。
- **ダンジョン経営・防衛モード（The Tower要素）**:
  - クリア後のエンドコンテンツとして、自分が潜ったダンジョンを拡張し、やってくる冒険者を迎え撃つ逆タワーディフェンスモードの追加余地をコード設計に組み込む。
